# Визуальное ревью сцены заезда

Тесты GUT проверяют числа (скорость, кадр, бюджет), но не то, как мир выглядит. Без
скриншота любое «стало красивее» — догадка. Правило: **нет снимка — нет приёмки визуала**.

## Как снять

```bash
./scripts/screenshot.sh <каталог> [скорость_кмч=32] [каденс=90] [дистанции_м=0,400,900,1500]
# пример: ./scripts/screenshot.sh screenshots/after 32 90 0,250,600,1200,1800
```

- Нужен Godot 4.7 (`GODOT=/путь/к/godot`, по умолчанию `godot` из PATH или `/opt/godot/godot`).
  В облачном контейнере его нет — скачать тот же релиз, что в CI (`GODOT_VERSION` в
  `.github/workflows/ci.yml`), в `~/godot/godot`.
- Без дисплея скрипт сам идёт через `xvfb-run`; рендер — `gl_compatibility` (Mesa llvmpipe).
  Forward+ на устройстве даст ту же композицию, но может отличаться SDFGI, объёмным туманом,
  SSAO/SSR — эти эффекты по скриншоту из контейнера не оцениваются, только `[ручная проверка]`.
- Файлы `ride_<дистанция>m.png`, 1280×720. Смотреть инструментом Read (он показывает картинку).
- Каталог `screenshots/` в `.gitignore`. Эталоны «до/после» для документов — в
  `docs/game/shots/<дата>-<тема>/`, только когда снимок нужен как аргумент в документе.

## Порядок

1. Снять «до» на тех же дистанциях, что будут «после» (иначе сравнение нечестное).
2. Внести правку. Снять «после».
3. Пройти чек-лист ниже по каждому кадру; записать в отчёт номер пункта и что видно.
4. Если правка — по задаче с критериями `[визуальная проверка]`, сослаться на файлы снимков.

## Чек-лист кадра (вид от третьего лица, 1280×720)

Композиция и читаемость
1. Есть земля до горизонта: ниже линии горизонта нет «пустого неба».
2. Горизонт виден и не завален; небо — градиент/небесный материал, не сплошная заливка.
3. Велосипедист читается силуэтом за 0,5 с: контраст с дорогой и фоном, понятно, что это человек на велосипеде и куда он едет.
4. Дорога — главная направляющая линия кадра, уходит к точке схода; видна разметка/обочина.
5. Глубина: минимум три плана (передний — дорога/обочина, средний — объекты, дальний — рельеф/силуэты), воздушная перспектива (туман/дымка темнеет и светлеет к горизонту).

Свет и цвет
6. Есть направленный свет и тени, тени не «чёрные дыры» (ambient/небо подсвечивают).
7. Палитра совпадает с арт-библией (`docs/game/art-bible.md`), если она есть; насыщенность не спорит с цветами зон мощности HUD (`src/ui/hud/zone_palette.gd`).
8. Нет пересвета/провала по яркости в зоне HUD (цифры поверх 3D должны оставаться читаемыми).

Мир
9. Объекты окружения разнообразны: нет одинаковых коробок через равный шаг; видна вариация масштаба/поворота/типа.
10. Ощущение скорости: объекты у дороги проходят мимо камеры, есть мелкая деталь у края кадра.
11. Нет артефактов: z-fighting, швы дороги, объекты в воздухе или в дороге, мерцание, обрезка камерой.

Бюджет
12. Изменение не ломает сцену и бюджет `docs/perf_budget.md`: `./scripts/test.sh -gselect=test_ride_scene` и `-gselect=test_scene3d_acceptance`.

## Формат вывода в отчёте

```
VISUAL: снимки <каталог> (дистанции …)
- п.1 ✗ ниже горизонта пустое небо на всех кадрах
- п.9 ✓ три типа деревьев, разный масштаб
ИТОГ: N/12, блокирующие: п.…
```
