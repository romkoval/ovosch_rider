## Карточка

> Заголовок карточки до разделения: T-125 — Приём ссылок и файлов из системы `[native-ble]` — `todo` — P0

Срез 0.5. Исполнитель — developer (нативный плагин iOS). Размер M. Зависит: T-122; ответ на Н-28.
Почему. Схема `ovoschrider` и типы документов объявлены в `platform/ios/Info.plist.template`, но приложение не принимает открытие URL и файлов: вход в Strava на iPad не вернётся в приложение (STR-01 п.7), «Открыть в…» не работает (IMP-03 п.4).
Что сделать. iOS: обработка открытия URL (custom scheme и file URL) → сигнал в Godot; `ovoschrider://strava?code=…` → `StravaOAuth` (и `ovoschrider://intervals` для T-128); `.zwo/.erg/.mrc` → копия в песочницу → экран подтверждения импорта (IMP-03 п.4). macOS: «Открыть с помощью» из Finder → тот же путь (если движок не доставляет файлы сам). GDScript-сторона — точка входа в слое по Н-28.
Закрывает: STR-01 п.7 (мобильная схема), IMP-03 п.4.
Критерии авто: GDScript-обработчик на поддельных URL — код Strava извлекается, файл передаётся импорту, неизвестная схема игнорируется без ошибок; CI собирает плагин. Ручные: протокол T-127.
