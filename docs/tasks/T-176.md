# T-176 — Флаг ERG в сэмпле — по факту, а не по выбору игрока `[game]`

Статус, приоритет и очередь — **только** в таблице `docs/backlog.md` (раздел 2). Здесь — описание, критерии приёмки, история и вердикты.

## Задача

- Исполнитель: developer. Размер: S–M.
- Зависит от: T-161 (доработка по У-36 — признак «ERG недоступен» в `TrainerDevice`), T-162 (доработка — предикат «ERG действует» и общий `workout_session.gd`). Н-77 (б) — до ответа по предложению реестра (не держит).
- Почему: замечание game-designer к `hud.md` п. 17, следствие У-36 и У-37 (журнал requirements «Станок без ERG и цель по станку», 2026-10-10): сейчас флаг ERG сэмпла пишется по выбору игрока (`erg_enabled`) даже при недоступном ERG, и сохранённый заезд и история могут пометить заезд как ERG.

## Что сделать

1. Одно определение «ERG действует» (WRK-08 п.7) — `smart` ∧ ERG доступен (DEV-10 п.5) ∧ переключатель «вкл» ∧ у текущего шага есть цель (не FreeRide / MaxEffort). Если T-162 уже завела предикат — переиспользовать, второго не делать.
2. `SampleStream` / `WorkoutSession` пишут в сэмпл этот флаг (WRK-08 п.2), а не `erg_enabled`. Следствие: шаг FreeRide при ERG вкл — флаг «выкл».
3. Поле цели сэмпла по станку — только при флаге «вкл» (DEV-10 п.6), иначе цель плана с множителем (сверить с T-162, не дублировать).
4. Признак «ERG» сохранённого заезда, истории и экспорта — только из флагов сэмплов (LOC-01 п.4), ни одна пометка не берётся из выбора игрока. Найти все места, где пометка берётся из `erg_enabled` / метаданных выбора.
5. Обрыв связи со станком (DEV-08) флаг не меняет — обрыв пишется отдельным событием (Н-77 (б), до ответа так). Старые заезды читаются без пересчёта.

## Критерии приёмки

- REQ-WRK-08 п.7 — `[авто]`, план «60 с 150 Вт, 60 с FreeRide, 60 с 200 Вт»:
  - FTMS, ERG доступен, переключатель не трогали → «вкл» в сэмплах 1–60 и 121–180, «выкл» в 61–120;
  - ERG выключен на 30-й и включён на 150-й секунде → «выкл» в 31–149 (±1 с), «вкл» в 1–30 и 150–180;
  - FTMS с битом 3 `0x2ACC` = 0 при переключателе по умолчанию «вкл» → «выкл» во всех 180; то же на FE-C без бита 1 страницы 0x36;
  - отказ `80 05 02` посреди заезда — по DEV-10 п.5 (г): t ≤ 60 «вкл», t ≥ 62 «выкл»;
  - `power_meter` → «выкл» во всех сэмплах;
  - обрыв связи на 30 с посреди шага с целью при ERG вкл → флаг не меняется, событие обрыва есть.
- REQ-WRK-08 п.2 — `[авто]`: состав сэмпла прежний, флаг — по п.7.
- REQ-LOC-01 п.4 — `[авто]`: заезд на станке без ERG (бит 3 = 0) при переключателе «вкл» — в сохранённом заезде и в строке истории пометки «ERG» нет; заезд с ERG — есть; события переключения и «ERG недоступен» сохранены (событие — T-162).
- Регрессия: WRK-08 п.1, 3–6, WRK-09 п.3 (тест эквивалентности — различается только флаг), LOC-01 п.1–3, LOC-02, LOC-05, STR-02; чтение старых заездов; полный прогон GUT зелёный.
