AVT-01 п.5 закрывается целиком после T-163. Причина: T-108 сдана до появления критерия, задача мелкая и не требует пересдачи 28 слотов.
Почему. Владелец хочет «докручивать» персонажа (велоформа, очки, туфли). Данные внешности должны жить отдельно от геометрии и храниться в профиле (у каждого профиля свой гонщик — PRF-04), формат слотов фиксируется сейчас, пока T-106a строит конвейер модели.
Уточнение 2026-10-04 (спека T-104 ред. 2, «Слоты внешности»): **28 слотов** (ред. 1 — 26; добавлены `body.figure` — `m`/`f`, по умолчанию `m`, и `hair.style` — `short`/`tail`, по умолчанию `short`; фигура и причёска независимы); **5 пресетов** — `classic` (по умолчанию), `sunrise`, `alpine`, `sprint`, `stealth` (тёмный, разрешён владельцем); ключи переводов `ui.menu.rider_look.preset.<ключ>`; формат хранения — словарь «слот → строка» и `version` = 1 (формат не выпущен, новые слоты входят в `version` 1; данные без них → значения по умолчанию); тип «цвет формы» — ключ палитры формы спеки (16 ключей), `skin.tone`, `hair.color`, `glasses.lens` — свои перечисления. Числа и списки значений — только из спеки (У-21), не дублировать в коде вручную без теста сверки.
Что сделать. `RiderLook` (`RefCounted`, без `Node`, в `src/profiles/`): слоты по таблице T-104 (велоформа — джерси/шорты/носки: цвета, узор; шлем — модель + цвет; очки — модель/линза/нет; туфли — модель + цвет; перчатки; велосипед — рама, ободья; кожа/волосы — если спека решит); `to_dict()/from_dict()`, проверка значений по слоту; пресеты по умолчанию (названия — ключи переводов); поле профиля `rider_look`, сохранение через `ProfileRepository` (атомарная запись как у прочих полей). UI нет (T-111).
Файлы: `src/profiles/rider_look.gd` (новый, + `.uid`), `src/profiles/profile.gd`, `src/profiles/profile_repository.gd`, `assets/i18n/strings_menu.csv` (только названия пресетов), `tests/unit/profiles/test_rider_look.gd`.
Закрывает: REQ-AVT-01; регрессия REQ-PRF-01, PRF-04.
Критерии авто: профиль без поля `rider_look` читается с внешностью по умолчанию (`classic`); данные `version` 1 без `body.figure`/`hair.style` → `m`/`short`, прочие слоты сохранены; round-trip `to_dict()/from_dict()` и через `ProfileRepository` (новый репозиторий на том же каталоге) по каждому из 28 слотов; неверное значение одного слота → значение по умолчанию только в этом слоте, остальные сохраняются; у двух профилей внешность независима; 6 пресетов спеки (ред. 4, с `volga_union`) валидны без замен, названия — непустые ru и en; `src/profiles/` не зависит от `src/scene3d/` (тест архитектуры).
