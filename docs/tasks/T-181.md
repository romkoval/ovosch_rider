# T-181 — Catalog route in the session: profile, grade, coordinate by distance, end of route `[game]`

Статус, приоритет и очередь — **только** в таблице `docs/backlog.md` (раздел 2). Здесь — описание, критерии приёмки, история и вердикты.

## Задача

- Executor: developer. Size: M.
- Depends on: T-180. Н-78 (г) (end of route), (е) (±25 % clamp, 200 km) — proposals apply until answered.
- Why: REQ-D3D-11 — the speed model and SIM ride the real route's h(s) / g(s), and every distance maps to a (lat, lon). Real routes are usually open, while `RouteProfile` today requires a closed loop (`ERR_NOT_CLOSED`) — end-of-route handling ("out and back") is new.

## Что сделать

1. Route profile from catalog data: h(s), g(s) by the D3D-08 definitions (step ≤ 10 m, 100 m grade window); grade fed to the speed model and SIM clamped to −25 … +25 %.
2. Coordinate by distance: linear interpolation of lat/lon between bracketing points; s = 0 → first point, s = L → last.
3. End of route: closed (first–last ≤ 50 m) → next lap from s = 0 (as D3D-03); open → reverse pass L − (s_cum − L), opposite grade sign, then forward again; session never ends by itself (FRD-07 p.1).
4. Session wiring: free ride and plan workouts can run on a catalog route instead of a stylized track profile; SIM gets the route grade (sign flipped on the return pass); WRK-09 p.7 path (no commands) unchanged.
5. Long routes: profile and coordinate lookup accuracy independent of point count (200 km fixture).

## Критерии приёмки

- REQ-D3D-11 p.4 `[авто]` — "climb": L = 2.00 ± 0.01 km, gain 50 ± 1 m, max grade 5.0 ± 0.1 %; +30 m spike → |g(s)| ≤ 25 %.
- REQ-D3D-11 p.5 `[авто]` — endpoints ±0.5 m; "meridian" s = 5 559.75 m → latitude of point 51 ±1 m; 100 random s on a bent fixture → along-route distance = s ± 1 m.
- REQ-D3D-11 p.6 `[авто]` — closed / open rules; "climb" 2 500 m → coordinate at 1 500 m, grade −5.0 ± 0.1 %; 4 500 m → coordinate at 500 m.
- REQ-D3D-11 p.7 `[авто]` — D3D-02 p.6, D3D-08 p.13 (speed part), FRD-04 p.2, 4, 5, 8, FRD-05 p.1–3 pass on the route profile; return pass sends the opposite grade.
- REQ-D3D-11 p.11 `[авто]` (accuracy part) — p.5 accuracy on the 200 km fixture.
- Regression: D3D-02, D3D-03, D3D-08, FRD-04, FRD-05, FRD-07, WRK-09 (stylized tracks unchanged).
