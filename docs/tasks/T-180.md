## Что сделать

1. Route data format (points: latitude, longitude, elevation) and catalog entry: stable unique id, ru/en name and type caption, stylized world (D3D-08 environment set), geometry source + license, elevation source + license. Keep it separate from the four stylized tracks in `RouteCatalog` (their ids and behaviour do not change).
2. Loader for shipped route data (`res://`), haversine segment length (R = 6 371 008.8 m), cumulative s and L.
3. Validation over every catalog route (test fails with route id + rule): ≥ 2 points, every point has elevation, no consecutive identical points (< 0.01 m), no segment > 50 m, L ≥ 1 km; route source/license missing from `docs/publishing/licenses.md` fails.
4. Fixtures in `tests/fixtures/routes/`: "meridian", "climb", "bend", 200 km / 20 000 points, one fixture per validation rule.
5. Attribution: «© OpenStreetMap contributors» with a link to the OSM copyright page on About / licenses (strings ru/en); `docs/publishing/licenses.md` section for route data (ODbL 1.0 share-alike — how it is met; DEM attribution if required). Card attribution — T-183.
