## Что сделать

(`docs/game/design.md`, `docs/game/ui.md`, `docs/game/hud.md`, макеты.)
1. Старт без станка: что видит пользователь на экране плана и главном, если станка нет, но есть измеритель мощности; если нет ни того, ни другого. Как выбирается режим.
2. HUD без ERG: цель интервала, подсказка «выше / ниже цели» (полоса допуска, порог, сглаживание; ориентир Н-23), индикация «без управления станком»; кнопки интенсивности WRK-07 меняют показываемую цель.
3. Режим «по ощущениям» — не делается (У-29; Н-71 (а)).
4. Свободная езда без умного станка с измерителем мощности.
5. Пометка таких заездов в истории и на итоге.
6. Предлагаемые критерии (`[авто]` / `[визуальная проверка]`) для requirements; снимки «до».
