Что сделать. `RiderModel.apply_look(look: RiderLook)` меняет только части своего слота (по спеке ред. 2: цвета регионов — запись палитры материала; модель — подмена `mesh` у того же узла `Body` (`body.figure`), `Hair` (`hair.style`), `Helmet`, `Eyewear`, `ShoeL/R`, `FrontWheel/RearWheel`; `glasses.model` = `none` — `visible = false`) без пересоздания узлов; все варианты сеток загружаются заранее; `RideScene.set_rider_look`; экраны заезда передают внешность выбранного профиля (в `src/ui/{workout,free_ride}/*_screen.gd` — только передача). Пружина хвоста — не здесь (T-106a2, решение менеджера).
Файлы: `src/scene3d/{rider_model,rider,ride_scene}.gd`, `src/ui/workout/workout_screen.gd`, `src/ui/free_ride/free_ride_screen.gd` (только передача), тесты.
Дополнение 2026-10-05 (фото-референс владельца; спека ред. 4.6, 13a0a07; REQ-D3D-09 п.20–22, AVT-02 п.5 — a07517f): на кадрах каждого пресета — правило шлема п.20 целиком (кадры `work` и `rear_low`, `flat` 0 м, φ 0/90/180/270, на каждый пресет; модели шлема вне пресетов — при внешности по умолчанию); Г9 и Г11 на тёмных пресетах (`stealth`, `volga_union`) — по п.21, карманы — на кадрах `classic`; чек-лист Ф целиком на пресете `volga_union` — п.22 (на манекене действуют Ф6–Ф12; регрессия кадров T-106a3, теперь полным пресетом, а не записью палитры). Пять главных расхождений манекена с фото по форме T-109 не снимает (это T-106b′, T-106c′).
Закрывает: REQ-AVT-02 (на манекене; п.3–5 на итоговой модели — повторно в T-106c′, запасной путь — T-106c), D3D-09 п.20 и п.22 на манекене при каждом пресете, п.21; регрессия REQ-D3D-05 п.4, D3D-07 п.2, D3D-09 п.1–5.
Критерии авто: смена одного слота меняет только части этого слота (цвета, вариант и видимость остальных частей до и после совпадают) — для каждого из 28 слотов; после 20 смен пресетов те же узлы (`instance_id`), число `MeshInstance3D` и материалов не выросло; REQ-D3D-09 п.1–5 проходят при каждом из 5 пресетов (обе фигуры); профиль без поля → в сцене внешность по умолчанию; без аллокаций в кадре. Визуально: `work` и `rear34_l` при φ = 90° на каждый из 5 пресетов (на манекене): пресеты различимы без подписи, у `sprint` нет очков, у `sunrise` и `stealth` — хвост; `stealth` на `flat` 0 м и `mountains` 1000 м — плечи, спина и шлем отделены от асфальта ободком (HSV V ≥ 0.45); правило шлема п.20 на кадрах `work` и `rear_low` каждого пресета; п.21 на `stealth` и `volga_union`; чек-лист Ф (Ф6–Ф12) на `volga_union` — не ниже 85 % видимых без провала по Ф7, Ф12, построчно; вердикт game-designer. Контраст тёмных пресетов как данные (AVT-01 п.5) — T-163.
