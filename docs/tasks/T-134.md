## Карточка

> Заголовок карточки до разделения: T-134 — Mac App Store сборка `[game]` — `todo` — P0

Срез 0.6. Исполнитель — developer (инфраструктура сборки). Размер M. Зависит: T-124; Apple Developer (сертификаты Mac App Store).
Что сделать. Второй пресет macOS для App Store: sandbox (`device.bluetooth`, `network.client`, `network.server` для loopback OAuth, `files.user-selected.read-write`) по `platform/macos/entitlements.template.plist`, подпись Apple Distribution, `.pkg`, выгрузка в App Store Connect (TestFlight для Mac) из CI; ad-hoc артефакт для владельца сохраняется. Проверить в sandbox: BLE, loopback OAuth, импорт и экспорт FIT, Keychain.
Закрывает: NFR-07 п.2, 5 (подготовка macOS).
Критерии авто: CI собирает и подписывает `.pkg`; `codesign -d --entitlements` показывает нужные права и только их; `Info.plist` содержит Bluetooth-описание. Ручные: протокол T-137.
