## Карточка

> Заголовок карточки до разделения: T-147 — Release-сборка падала при запуске (`[editable]` у вложенной сцены `AppBar`) `[game]` — `done` — P0 (дефект)

Найдено владельцем на MacBook при проверке 0.3.0-preview.1: приложение из CI падало сразу при запуске. Исполнитель — developer. Размер S. Исправлено: 8c3f88b, вошло в 0.3.0-preview.2 (cd337ca).
Причина. В `src/ui/devices/devices_screen.tscn` узлы `ScanIndicator`, `AutoConnectCheck`, `ScanButton` добавлены внутрь вложенной сцены `AppBar` без `[editable path="Root/AppBar"]`. Редактор и GUT такие узлы загружают, а экспорт их теряет: `%ScanButton` = null, GDScript в release не проверяет вызов у null, SIGSEGV в `Node.get_children`. Воспроизведено на экспорте Linux release из шаблонов 4.7.
Что сделано. Сцене добавлен `[editable]`; тест — все сцены `src/` с узлами внутри вложенных сцен помечены `[editable]`; экспорт Linux release запускается (600 кадров после правки, 900 — в сборке 0.3.0-preview.2) без ошибок; полный прогон 3564/3564.
Закрывает: REQ-DEV-01 (экран устройств открывается в release-сборке); регрессия NFR-07 (сборка запускается).
Статус `done` поставлен по указанию оркестратора: принято по тесту, полному прогону и прогону экспорта, приёмки tester не было. Tester сверяет в ближайшей волне приёмки (тест `[editable]` и прогон экспорта). Ручная проверка — владелец запускает 0.3.0-preview.2 на MacBook. Чтобы такие падения ловились до владельца — T-148.
