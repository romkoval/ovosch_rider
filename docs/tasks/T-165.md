# T-165 — Экран «BLE-отладка»: сырые данные устройств на Mac `[game]`

Статус, приоритет и очередь — **только** в таблице `docs/backlog.md` (раздел 2). Здесь — описание, критерии приёмки, история и вердикты.

## Задача

- Исполнитель: developer. Размер: M.
- Зависит от: — (подключение на Mac исправлено в 207ce08).
- Почему: срочное поручение владельца 2026-10-05. Tacx Neo 11565 на Mac виден приложением только как «cadence»: после подключения у него сервисы 180A, 1816, 1818, 669AA501-…, 6E40FEC1-… (Tacx FE-C over BLE), FTMS 1826 нет; у Quarq — 00002000-…, 180A, 180F, 1818, FE51, FE59. Нужен инструмент, чтобы видеть, что устройство реально рекламирует и отдаёт, а не гадать.

## Что сделать

1. Модель `BleDebugModel` (`src/devices/ble/debug/`: путь чтения характеристик — только в слое устройств, REQ-NFR-06 крит. 5; `RefCounted`, без UI, поверх контракта `BleBridge`): скан без фильтра (`start_scan([])`) и переключатель «фильтр приложения» (`BleUuids.SCAN_SERVICES`); список устройств — имя, полный id, RSSI, UUID пакета (как есть и нормализованные), объединение UUID за сеанс, тип по `BleScanner.kind_from_services`.
2. Подключение/отключение; после `connected` — `discover_services`; дерево «сервис → характеристики» с именами (FTMS 1826: 2AD2, 2AD9, 2ADA, 2ACC, 2AD8, 2AD6, 2AD5; CPS 1818/2A63; CSC 1816/2A5B; HRS 180D/2A37; Battery 180F/2A19; Device Info 180A; Tacx FE-C 6E40FEC1 — FEC2 notify, FEC3 write), неизвестные — как есть.
3. Характеристика: «Прочитать», «Подписаться/Отписаться», последнее значение в hex со временем и расшифровкой (кодеки проекта: Indoor Bike Data, CPS, CSC, HR, Battery, ответы Control Point, Machine Status, Feature, диапазоны; Device Information — текст; ANT FE-C страницы 0x10, 0x11, 0x19, 0x30, 0x31, 0x47, 0x50, 0x51), «Записать hex» с выбором «с ответом».
4. Пресеты: FTMS Control Point — Request Control `00`, Start `07`, Set Target Power 150 Вт `05 96 00`, Reset `01`; FE-C (FEC3) — Target Power 150 Вт, страница 0x31 в ANT-сообщении `A4 09 4F 05 31 FF FF FF FF FF 58 02 73` (XOR-сумма). «Прочитать 180A» — все строковые характеристики Device Information (производитель, модель, прошивка).
5. Журнал событий моста с меткой времени (device_found — не чаще раза в секунду на устройство, кроме первого пакета и пакета с новыми UUID; connected, disconnected с причиной, services_discovered со списком, notification, characteristic_read, write_done, error с кодом и сообщением, adapter_state_changed); «Скопировать журнал» (буфер обмена); каждое событие — в `DiagLog`, категория `ble_debug`, id — меткой SHA-256, имя — как есть.
6. Экран `BleDebugScreen` (`src/ui/ble_debug/`): тема приложения, без отдельного дизайна; вход — скрытая строка «BLE-отладка» в «О программе» (5 нажатий на «Версию»), работает в release; общий мост приложения; пока экран открыт, сканирование и автоподключение `ConnectionManager` на паузе (через его публичные методы), при выходе — возвращаются. Переводы ru/en — `strings_menu.csv`.

**Д-1 (п.5).** `BleDebugScreen.connect_selected()` пишет в журнал заметку с полным id, если устройство уже подключено приложением: `model.note("device %s is also connected by the app; its link is shared" % _selected_device)` → `DiagLog` (`ble_debug`/`note`, поле `text`). Шаги: приложение подключило пульсометр (`connect_sensor(id, KIND_HR)`), открыть «BLE-отладку», скан, выбрать тот же пульсометр, «Подключить». Ожидается: в `DiagLog` нет полного id (только метка `device_tag`). Фактически: `{"cat":"ble_debug","ev":"note","data":{"text":"device 1B7F0C3E-…-0000000HRM01 is also connected by the app; its link is shared"}}`.

Ручные шаги для владельца (Mac, release-сборка CI, Tacx Neo 2T и Quarq): 1) «О программе» → 5 нажатий на «Версию» → «BLE-отладка» → «Открыть»; 2) «Сканировать» без фильтра — Neo и Quarq в списке, UUID рекламы как есть; включить «Фильтр приложения» — скан перезапущен; 3) подключить Neo — дерево с 6E40FEC1 (FEC2/FEC3), 1818, 1816, 180A; 4) выбрать FEC2 → «Подписаться» — значения страниц 0x10/0x19 обновляются; 5) пресет «FE-C: мощность 150 Вт» — в журнале write_done ok и страница 0x47 «last command 0x31, status pass», сопротивление педалей растёт; 6) «Прочитать 180A» — производитель, модель, прошивка текстом; 7) Quarq: подписка 1818/2A63 — мощность и каденс при вращении шатуна; 8) «Скопировать журнал» — вставить в текстовый редактор, строки с метками времени; 9) «Назад» — на экране «Устройства» скан и автоподключение приложения работают как до входа.
