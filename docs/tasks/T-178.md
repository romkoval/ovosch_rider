## Что сделать

1. In `docs/game/` (design.md / art-bible.md, game-designer's choice): how a real-route world is built (first routes — South China and islands, owner's answer to Н-80; the existing four environment sets may not fit — say which new set is needed, if any) — which stylized environment set (D3D-08) a catalog route uses and how it is chosen per route; road look on real geometry (width, shoulders, banking within the p.10 (г) limits, hairpins).

4. Scenery along the route: placement rules (clearance from the road axis ≥ half-width + 1 m), density per environment set, landmarks (if any) on real routes.
5. Chunk streaming from the player's point of view: what may pop in, at what distance, what must never pop (road ahead within N m).
6. Frame set for p.12 ("climb" 500 / 1 500 / 1 950 m, "bend" 900 / 1 000 / 1 100 m) and "before" frames of the current stylized tracks; proposed `[визуальная проверка]` / `[авто]` criteria for requirements if anything new is needed.
