## Что сделать

1. Auto screenshot at a random moment around the middle of the workout (exact window and count — updated LOC-08 p.1; randomness seedable in tests), manual `P` key / HUD button (≥ 2 s apart, ≤ 20 per ride, limit message ru/en).
2. Capture of the ride screen layers (3D + HUD + hint slot; no dialogs, menus, debug overlays) through a substitutable frame source.
3. Storage through `RideRepository`: JPEG, long side ≤ 1920 px, ≤ 1.5 MB, ordered by session second, kind auto/manual; written at capture time (crash-safe); deleted with the ride; per-profile isolation.
4. Setting «Автоснимки» (Workout section, on by default, per profile).
5. Screenshot scenario frames (`flat` 0 / 1 900 / 4 200 m plan; `mountains` 6 000 m free ride).
