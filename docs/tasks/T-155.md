## Карточка

> Заголовок карточки до разделения: T-155 — Подсказка интервала на превью плана: вид и поведение `[design]` — `review` — P2

Сдано (2026-10-05, d34c7b6): `docs/game/ui.md` п. 8.3.1 (подсказка шага: своя, три строки «длительность · Вт · %», зона, повтор и каденс; касание показывает, отпускание закрепляет), 8.3.3 (кто получает ввод: желоб — FTP, поле — шаги), 8.3.4 (предлагаемые критерии 1–6 для UIX-03 п.9), 13.5 (решения и вопросы владельцу Н-68, Н-69). Снимков «до» нет: `ui_screenshot.sh` в облаке не доходит до экрана плана за 20+ мин — «до» снимает developer в T-156, вердикт по кадрам «после» — game-designer. Ждёт сверки tester по критериям карточки (п.1–5).
Срез — предложение менеджера: 0.3.1 (0.3 не блокирует; если макет и код успеют в паузах — войдёт в 0.3). Исполнитель — game-designer. Размер S.
Почему. На экране плана крупное превью (`PlanPreview` с `detailed = true`, `src/ui/common/plan_preview.gd`, наследник `HudChart`) рисует столбики шагов без подписей. Владелец хочет видеть длительность и мощность интервала при наведении мышью, а на iPad/iPhone — по касанию или удержанию.
Что сделать (`docs/game/ui.md`, п. 8.3 — панель предпросмотра):
1. Содержимое подсказки. Длительность шага (мм:сс); цель в Вт и % FTP с учётом FTP профиля и интенсивности по умолчанию — те же числа, что рисует превью; рампа — «от–до» (Вт и %); зона мощности (номер, название, цвет — как у сегмента); FreeRide — «свободно». Предложить, нужны ли: номер повтора («2 / 3» для блока повторов), каденс-цель, текстовая подсказка шага. Для шагов в ваттах (`.erg`) % FTP — от FTP профиля.
2. Ввод. Мышь — наведение (шаг ищется по горизонтали, вся высота графика — область), подсветка шага, уход указателя — скрыть. Касание — нажатие показывает, удержание с ведением пальца переключает шаги, отпускание — оставить или скрыть (предложить); касание вне графика скрывает. Клавиатура — при фокусе на превью стрелки ← → переключают шаг (UIX-05 п.5). Короткие шаги уже 44 pt не делаются отдельными целями: поиск по позиции, а не по кнопке на шаг (UIX-05 п.1 — предложить, как это записать).
3. Размещение. Над шагом и не под пальцем; внутри окна при любой раскладке (compact / regular / wide); ru/en без обрезки (NFR-08, UIX-05 п.2, 3); стиль — всплывающая подсказка темы (тень 24 lp, `ui.md` п. 4), не новая сущность.
4. Где нет: миниатюры в карточках списка (UIX-03 п.4 — «на миниатюрах нет … подписей»); график HUD во время езды — вне этой задачи (если нужно — предложить отдельно).
5. Предлагаемые критерии `[авто]` / `[визуальная проверка]` для requirements (Н-56); снимки «до» — план «Активация 3x6» (или фикстура той же структуры, FTP 300) на regular и compact.
