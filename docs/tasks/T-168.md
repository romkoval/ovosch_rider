# T-168 — Станок по Tacx FE-C over BLE: ERG, сопротивление, SIM `[integration]`

Статус, приоритет и очередь — **только** в таблице `docs/backlog.md` (раздел 2). Здесь — описание, критерии приёмки, история и вердикты.

## Задача

- Исполнитель: developer. Размер: M.
- Зависит от: T-167 (кодек FE-C, реализация станка, подключение). Н-70 (в), (г), (д) — до ответа по предложениям requirements; Н-61 (в) — бит 0 страницы 0x36 не трогать до ответа.
- Почему: REQ-DEV-11 (У-27) — управление эталонным Tacx Neo владельца по FE-C (FTMS у него нет, У-28). Вторая половина DEV-11 после T-167.

## Что сделать

1. ERG — страница 0x31 (п.6): цель × 4, uint16 LE, `write(id, FEC1, FEC3, bytes, true)`; сроки как у FTMS (WRK-02 п.2, п.3).
2. Подтверждение и повтор (п.7): повтор при `write_done(ok=false)` / `error`; запрос 0x47 страницей 0x46 после каждой 0x31, ожидание ≤ 2 с, статусы Pass / Fail / Rejected / Not supported.
3. Возможности (п.8): запрос 0x36, биты 0–2; без бита — соответствующая страница не уходит; нет ответа — всё доступно; запасной диапазон мощности DEV-10 п.7 (0..2000 Вт).
4. Фиксированное сопротивление — 0x30 (п.9 (а)); SIM — 0x33 с предварительной 0x32 при входе в SIM (п.9 (б)); переподключение и пауза (п.9 (в)).
5. Эквивалентность FTMS и FE-C за `TrainerDevice` (п.10).
6. Ручная часть DEV-11 п.11 — в протокол T-117 (Neo на Mac).

## Критерии приёмки

- REQ-DEV-11 п.6 — `[авто]`: 150 Вт → `A4 09 4F 05 31 FF FF FF FF FF 58 02 73`; 250 Вт → `… E8 03 C2`; 130 Вт → байты 6–7 `08 02`; запись не позже 1 с после границы интервала по метке журнала.
- REQ-DEV-11 п.7 (а), (б) — `[авто]`: один повтор; 0x46 с байтом 6 = `47`; Pass / Fail / Rejected / Not supported / нет ответа — по тексту пункта.
- REQ-DEV-11 п.8 — `[авто]`: фикстура `36 FF FF FF FF 00 00 03` → в свободной езде ни одной 0x33, на HUD «станок не поддерживает SIM»; цель 2400 Вт → `40 1F`.
- REQ-DEV-11 п.9 (а)–(в) — `[авто]`: 50 % → `… FF 64 B3`, 0/35/100 % → `00`/`46`/`C8`; 5.00 % → `… 14 50 50 C0`, −3.00 → `F4 4C`, 0 → `20 4E`, 12.34 → `F2 52`; 0x32 `32 FF FF FF FF 14 7F 64` перед первой 0x33; после `connected` — подписка и команда ≤ 1 с, на паузе — без записей.
- REQ-DEV-11 п.10 — `[авто]`: прогон п.10 на FTMS- и FE-C-фикстурах — одинаковые вызовы `TrainerDevice` и сэмплы; поиск `6e40fec`, `fe-c`, `fe_c`, `0x1826`, `2ad9` в `src/session/`, `src/domain/`, `src/ui/` пуст.
- Регрессия: DEV-02, DEV-10, WRK-02..07, FRD-04, FRD-05, NFR-01; полный прогон зелёный.
- DEV-11 п.11 — `[ручная проверка]` в протоколе T-117.
