## Карточка

> Заголовок карточки до разделения: T-156 — Подсказка интервала на превью плана: реализация `[game]` — `todo` — P2

Срез — как T-155 (предложение 0.3.1). Исполнитель — developer. Размер S–M. Зависит: T-155 (макет и критерии — `review`, d34c7b6; можно брать, макет сдан). Макет — `docs/game/ui.md` п. 8.3.1, 8.3.3, 8.3.4 (критерии 1–6); requirements переносит п. 8.3.4 в **UIX-03 п.9** — сверять с ним.
Что сделать — по макету T-155:
1. Поиск шага по позиции на крупном превью: по `x` — время, по времени — шаг модели `PlanChartModel` (те же сегменты, что рисуются, включая куски рамп и «свободно»; на границе — правый шаг; UIX-03 п.4 — одна модель и один рисовальщик).
2. Текст подсказки по макету — три строки: «длительность · Вт · %», зона, повтор и каденс; числа — из той же модели (FTP профиля, интенсивность по умолчанию, зоны профиля), а не пересчётом заново. `%` при интенсивности ≠ 100 % — по Н-68 (до ответа — по рекомендации: от фактических ватт).
3. Ввод по п. 8.3.3: наведение — подсказка, щелчок — закрепить; касание показывает сразу, отпускание закрепляет, вертикальное ведение — прокрутка; клавиатура — элемент фокуса «превью», ← / →, Home / End. Только при `detailed = true`. Ручку линии FTP не делает (T-158), но поле графика не должно перехватывать ввод желоба.
4. Переводы ru/en.
5. **Снимки.** В `scripts/dev/ui_screenshot.gd` — отдельный кадр экрана плана с открытой подсказкой и кадр с листом на compact, с запуском **только этого кадра** (аргумент выбора кадра): полный прогон скрипта в облаке не доходит до экрана плана за 20+ мин. Этим же запуском — снимки «до» (без подсказки) и «после» по критерию 6 п. 8.3.4 (ровный шаг, рампа, «свободно», первый и последний шаг; regular 1280×720 и compact 1280×590 с безопасной зоной; ru и en).
6. **Фикстура** той же структуры, что «Активация 3x6» владельца (FTP 300, 9 шагов, максимальная цель 279 Вт; структура — по описанию в T-149 / раздел 4, без персональных данных): для снимков и тестов подсказки; её же использует T-158 (предел жеста 345 Вт).
Файлы: `src/ui/common/plan_preview.gd`, `src/ui/hud/plan_chart_model.gd` (только поиск шага по времени, если его нет), `src/ui/plan/plan_screen.gd` (если подсказка — узел панели), `assets/i18n/strings_menu.csv`, `scripts/dev/ui_screenshot.gd` (кадр экрана плана и запуск одного кадра), `tests/fixtures/workouts/` (фикстура «как Активация 3x6»), `tests/`.
Закрывает: REQ-UIX-03 п.9 (подсказка шага; вносит requirements по `ui.md` п. 8.3.4, Н-56); регрессия INT-05 п.1–3, UIX-03 п.1, 4, UIX-05 п.1–3, 5, NFR-08.
Критерии авто (по `ui.md` п. 8.3.4 критерии 1–5 и UIX-03 п.9, когда внесён):
- план «10 мин 50 %, 5 мин 100 %», FTP 200: первый шаг → `10:00 · 100 Вт · 50 %` и `Z1 · Восстановление`; второй → `5:00 · 200 Вт · 100 %` и `Z4 · Порог`;
- рампа 50 → 75 % при FTP 300 → `150–225 Вт · 50–75 %`, зона `Z1 → Z2`; FreeRide → `свободно`, `без цели мощности`; шаг в блоке 3× → `повтор k из 3`; каденс 90 → `90 об/мин`;
- интенсивность по умолчанию 110 % → ватты подсказки = ватты сегмента (`110 Вт · 55 %` у шага 50 % при FTP 200 — по рекомендации Н-68); у шага в ваттах `%` — от FTP профиля;
- наведение показывает, уход указателя скрывает (если не закреплена); щелчок или касание закрепляет; касание вне превью и выбор другой тренировки скрывают; ← / → переключают шаг, у края фокус не уходит, Tab уводит и скрывает; у миниатюр подсказки нет, миниатюра не элемент фокуса;
- подсказка внутри окна и безопасной зоны для первого, последнего и самого высокого шага на всех разрешениях UIX и в compact, не пересекает свой столбик; при касании не накрывает точку касания; ru/en без обрезки;
- запуск одного кадра `ui_screenshot.gd` (экран плана с подсказкой) укладывается в время, приемлемое для облака (цифра — в отчёте);
- полный прогон зелёный.
Визуальная проверка — вердикт game-designer по кадрам критерия 6 п. 8.3.4. Ручная — касание на iPad (срез 0.5, UIX-05 п.7).
