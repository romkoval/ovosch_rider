## Карточка

> Заголовок карточки до разделения: T-152 — Тренировка без умного станка: сессия и устройства `[game]` — `todo` — P1 (MVP — предложение, Н-54)

Срез 0.4 (предложение; код — в паузах 0.3). Исполнитель — developer. Размер M. Зависит: T-151 (критерии), REQ по Н-53.
Что сделать.
1. План идёт по таймеру с источником мощности без станка: измеритель мощности (CPS), каденс (CSC или CPS), пульс (HRS). Ни одной команды управления (Control Point, Set Target Power, сопротивление, SIM).
2. Способ выбирает developer, с соблюдением DEV-09 п.1 и NFR-06 п.3: например, реализация `TrainerDevice` «без управления» поверх `SensorHub` в `src/devices/` (команды управления — пустые, телеметрия — от датчиков), чтобы `WorkoutSession` и исполнитель не менялись. Альтернатива — режим сессии; обоснование — в отчёте.
3. Запись 1 Гц (WRK-08), сохранение, FIT, выгрузка в Strava — как у обычного заезда. В метаданных — режим (например `trainer_mode`: `smart` / `power_meter` / `none`; имя — по REQ).
4. Режим без датчиков (если REQ его включит): таймер, цели, сэмплы с «нет данных» вместо 0.
5. Обрыв измерителя мощности — по правилам DEV-08 п.1, 2, 4 (переподключение, «нет данных», данные не теряются).
6. Для проверки без железа — эмулятор источника мощности без управления (рядом с переключателем T-150, в строках разработчика), если укладывается в заход. Иначе — отдельной задачей.
Файлы: `src/devices/` (реализация «без управления», правило старта по устройствам), `src/session/` (только если без этого нельзя), `src/storage/` (поле режима в метаданных, если его нет), тесты.
Закрывает: новый REQ (Н-53); регрессия WRK-01, WRK-08, DEV-05, DEV-08, LOC, STR, NFR-06.
Критерии авто (уточнит REQ). Сценарий с симулятором CPS без станка:
- Журнал моста пуст по командам управления.
- Сэмплы 1 Гц с мощностью от CPS.
- Переходы шагов — как WRK-01.
- FIT содержит мощность, каденс и пульс; задача выгрузки ставится как обычно.
- Без датчиков (если в REQ) таймер идёт, сэмплы — «нет данных».
- Тест архитектуры зелёный.
