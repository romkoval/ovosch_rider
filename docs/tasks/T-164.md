Наблюдение для T-161 (не дефект T-164: карточка п.2 разрешает строгую проверку отложить в T-161): у станка пустой список `services_discovered` идёт по старому пути «неизвестно». Воспроизведение на `StubBleBridge`: `set_device_services("neo", {})` → `connect_trainer("neo")` → состояние «подключено», станок запомнен; затем `error(SERVICE_NOT_FOUND)` (так нативный мост Apple отвечает на подписку без сервиса) → остаётся «подключено», причина NONE, запись не снимается.
