## Research (coordinator, 2026-10-10)

- Godot 4 `Window` flags cover most of it: always on top, borderless, per-pixel transparency (project setting `display/window/per_pixel_transparency/allowed` + transparent window/viewport background), mouse passthrough polygon for the transparent part. `ALWAYS_ON_TOP` is ignored for full-screen windows — ours is small, so fine.
- macOS catch: native full-screen video in Safari / Chrome (and the Apple TV app) lives in a separate Space; a normal always-on-top window does not appear there (TrainerRoad's "Minimal Mode" has exactly this problem — users switch to Firefox). Fix to try: from native code set the `NSWindow` `collectionBehavior` to `canJoinAllSpaces | fullScreenAuxiliary` and a higher window level (e.g. `NSFloatingWindowLevel` / `NSStatusWindowLevel`). We already have an Objective-C++ GDExtension (`native/ble/`) — add a small method there; window handle via `DisplayServer.window_get_native_handle(WINDOW_HANDLE, …)`.
- The app must keep running unfocused: BLE, ERG commands, recording continue; prevent App Nap (`NSProcessInfo beginActivityWithOptions:reason:`, e.g. `NSActivityUserInitiated | NSActivityLatencyCritical`) if needed. The 3D world is not rendered in this mode (save CPU/GPU for video playback).
- Controls: pause and skip-step buttons on the overlay. Global hotkeys are out of scope.

## What to do

1. Switch from the workout screen into the mini-HUD and back (a button on the workout HUD; a "back to full" button on the overlay). The session is not restarted, the timer does not jump; on return the full HUD and the 3D world resume.
2. Mini-HUD layout (plain, functional; final look is game-designer's job later): power + target, HR, cadence, step timer, next step; buttons pause and skip step. Values come from the same HUD model / session as the full HUD — no second source of truth.
3. Window: small size, always on top, borderless, per-pixel transparent background, mouse passthrough for the transparent part (buttons stay clickable). Restore the previous window size/position/flags on return.
4. Native (macOS): a method in the GDExtension that sets `collectionBehavior` = `canJoinAllSpaces | fullScreenAuxiliary` and a raised window level for the given window, and resets them on return; App Nap guard (begin/end activity) for the duration of the session if the unfocused test shows throttling. On non-Apple builds the method is absent / a no-op — GDScript checks availability and does not fail.
5. 3D rendering paused in mini-HUD mode (e.g. ride viewport `UPDATE_DISABLED` / scene processing off), the session and `SampleStream` keep ticking at 1 Hz.
6. Short spike result in "History": what worked over which apps, which window level was chosen, App Nap needed or not, CPU estimate — input for requirements and game-designer.

## Acceptance criteria

No REQ-ID yet (spike; requirements formalizes after the result). Regression REQ-IDs are listed below.

- `[авто]` mode switch: workout screen → mini-HUD → back; session state (step, elapsed time, ERG target) unchanged across both switches; HUD values in mini-HUD equal the full HUD model values for the same tick.
- `[авто]` window flags in mini-HUD: always on top, borderless, transparent set; mouse passthrough polygon not empty; all restored after return. Native call: invoked when the extension is present, skipped without error when absent (headless / stub).
- `[авто]` 3D rendering paused in mini-HUD (ride viewport update disabled / world not processing) and resumed after return.
- `[авто]` session keeps ticking with the window unfocused (headless where possible, `FakeTrainer`): plan "60 s 150 W, 60 s 200 W" run in mini-HUD → 120 samples at 1 Hz, ERG target changes to 200 W at the step boundary (±1 s); pause and skip-step buttons on the overlay act as the full-HUD ones.
- `[ручная проверка]` owner on his Mac (checklist — `docs/backlog.md` section 4, "Mini-HUD spike"): overlay visible over full-screen video in Safari, Chrome, Firefox and the Apple TV / QuickTime app, over a normal window, and survives switching Spaces; a training session keeps running unfocused for 10 minutes (ERG changes on step boundaries, samples recorded).
- Regression: WRK-05, WRK-06 (pause, skip), WRK-08 (samples), HUD-01, NFR-04 (screen does not sleep); full GUT run green.

Out of scope: Windows / Linux / iPad / Android, final visual design, global hotkeys, requirements entry.
