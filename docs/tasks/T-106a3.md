## Карточка

> Заголовок карточки до разделения: T-106a3 — Регионы цвета, палитра, контур и ободок, тень гонщика `[visual]` — `todo` — P0 (MVP, У-18)

Волна 5, после T-106a2 (TA-1). Исполнитель — technical-artist. Размер M. Зависит: T-106a2.
Что сделать.
1. Код региона в UV0 (U — регион 0–31, V — тон; спека «Регионы цвета в glTF») у всех частей манекена и велосипеда: `MeshKit` пишет код в UV вместо цвета вершин; цвет вершин гонщиком и велосипедом не используется. Велосипед — по составу спеки (`Bike` ≤ 2600, `FrontWheel`/`RearWheel` ≤ 1600, `CrankArm` ≤ 600 треугольников; регионы 23–31), включая второй вариант обода (`deep` 50 мм / `shallow` 30 мм — сетки колёс для слота `bike.rims`).
2. Один тун-материал гонщика с велосипедом (контур — `next_pass`): палитра внешности — параметр материала (32 цвета + блик линзы по правилу региона 19), тон по V с переворотом glTF, вес контура по региону (0 у 18, 19, 20, 25, 28, 29), сглаженные нормали контура. Палитра по умолчанию — `classic`; узоры джерси (`solid`, `side_panels`, `chest_band`, `shoulder_yoke`) — функция «значения слотов → цвета регионов 3–7» по схеме спеки (без зависимости от `src/profiles/`; вход — словарь значений, его даст T-109).
3. Ободок — аддитивный светлый (оттенок солнца, сила 0.35), не умножается на альбедо: виден на чёрной джерси.
4. Тень (спека «Тень гонщика»): `soft_shadow_filter_quality` ≥ 1, `directional_shadow_split_1` ≤ 0.15 при `max_distance` 90 м; стиль «жёсткой» тени сохраняется. Если замер T-116a на эталонном Mac (MacBook Pro M1 Pro, У-25) покажет фильтр дороже 1 мс кадра — остаётся только split (решение по замеру, в отчёт).
5. Строка в `docs/perf_budget.md`: «Гонщик с велосипедом: ≤ 18 500 треугольников (самые тяжёлые варианты), ≤ 10 `MeshInstance3D`, 1 материал, 0 текстур, ≤ 28 костей; эталон — MacBook Pro M1 Pro (MacBookPro18,3), У-25». В отчёте — максимум draw calls на «Перевале» до и после (риск «Draw calls без запаса», раздел 2).
6. **Сверка вида сзади с фото-референсом владельца 2026-10-04** (спека ред. 4.6, коммит 13a0a07, подраздел «Фото-референс 2026-10-04: сверка вида сзади»; REQ-D3D-09 п.20, 22 — a07517f). Палитра пресета `volga_union` записывается в материал напрямую (все видимые сзади слоты; полный пресет — T-109), шлем манекена — оболочка `red`, полоса `black` по правилу шлема спеки. Кадры (`gl_compatibility`, `--views`, `flat` 0 м): `work` при φ 0/90/180/270 и `rear34_l` при φ 90; для пунктов цвета — ещё `work` φ 90 на `mountains` 1000 м. Чек-лист Ф — пункты Ф6–Ф12 (на манекене действуют только они — REQ-D3D-09 п.22; Ф1–Ф5 — «н/п (форма)», Н-67 закрыт d34c7b6). Само фото в `docs/`, отчёты и коммиты не кладётся. Цена — 5–6 кадров, код продукта сверх п.1–3 не меняется.
Закрывает: REQ-D3D-09 п.6 (адресуемые части — узлы и регионы), п.7 (материал, узлы, строка бюджета), `[авто]`-часть п.12 по спеке (фильтр, split), п.20 (правило шлема на манекене с палитрой `volga_union` — кадры `work`; `rear_low` того же пункта — в T-106b′/T-106c′ и T-109 по пресетам), п.22 (Ф6–Ф12 на манекене); регрессия D3D-07 п.4, 6; механизм AVT-02 п.1, 2.
Критерии авто: каждая грань манекена и велосипеда — внутри одной колонки с отступом 10 %; запись цвета региона k меняет цвет только граней региона k (проверка по палитре материала и UV); вес контура по таблице регионов; четыре узора дают цвета регионов 3–7 по схеме спеки; уникальных материалов сцены не больше, чем до задачи; `MeshInstance3D` гонщика с велосипедом ≤ 10, треугольников ≤ 18 500; настройки тени в пределах спеки; строка бюджета есть. Визуально: рабочая камера четырёх трасс в Forward+ и Compatibility «до/после» (границы цветов чёткие — Г11); ободок на чёрной джерси (`jersey.main` = `black` записью палитры) на `flat` 0 м и `mountains` 1000 м — линия HSV V ≥ 0.45 (полный пресет `stealth` — T-109); тень `mountains` 1000 м «до/после» (Г13); кадры п.6 с палитрой `volga_union` — чек-лист Ф, пункты Ф6–Ф12, не ниже 85 % видимых пунктов без провала по блокирующим Ф7, Ф12, построчно в отчёте (D3D-09 п.22); шлем на `work` — красное пятно, а не тёмное (п.20 (г), Ф8); вердикт game-designer. Ручные: стоимость фильтра тени и 60 FPS на MacBook Pro M1 Pro — 20-минутный замер журналом T-116a (условие выпуска 0.3, У-25).
