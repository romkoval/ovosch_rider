# Реестр ассетов

У каждого внешнего ассета в сборке есть строка здесь: источник, лицензия, где лежит.
Ассет без лицензии, пригодной для магазинов приложений, не коммитится. Мир заезда сейчас
полностью процедурный (`src/scene3d/`), внешних 3D-ассетов нет. Шрифты GUT
(`addons/gut/fonts/`) относятся к тестовому аддону и в продукт не входят.

| Ассет | Где в проекте | Источник | Лицензия | Статус | Зачем |
|---|---|---|---|---|---|
| Inter 4.x, вариативный `Inter[opsz,wght].ttf` (~0.9 МБ) | `assets/fonts/inter/Inter-Variable.ttf` + `OFL.txt` | https://github.com/rsms/inter/releases (или https://github.com/google/fonts/tree/main/ofl/inter) | SIL OFL 1.1 | предложен, не добавлен | единый шрифт HUD и меню, `tnum`, кириллица (`hud.md` п. 5.2, `ui.md` п. 5) |
| Lucide icons (SVG, ~35 шт., список — `ui.md` п. 7) | `assets/icons/lucide/` + `LICENSE` | https://lucide.dev, https://github.com/lucide-icons/lucide | ISC (часть иконок из Feather — MIT) | предложен, не добавлен | иконки меню и HUD |
| Переключатель, бегунок слайдера (свои SVG) | `src/ui/theme/icons/` | рисуются в проекте | свои | предложен | `ui.md` п. 9.1 |

При добавлении ассета: файл лицензии кладётся рядом, строка здесь переходит в статус
«в проекте», а в «О программе» (`settings_screen`, список ПО и лицензий) появляется запись.
