# Трассы: равнина, холмы, горы, приморье

Требования: REQ-D3D-08, FRD-02, FRD-03, FRD-07 (ТЗ ред. 2). Решение владельца: четыре
трассы — равнина (~10 км), холмы (~15 км), горы с длинным подъёмом (~20 км), приморье с
рекой и мостом. Мир и стиль — `art-bible.md`; превью в меню — `ui.md` п. 8.4; панель
рельефа в HUD — `hud.md` п. 8. Макет каталога — `shots/2026-10-03-ui-mockups/tracks_1280.png`.

Сейчас трасса одна: `LoopTrack`, петля ~2.1 км с перепадом ±3 м. Снимки текущего мира —
`shots/2026-10-03-toon-world/` (по сути это уже «холмы»).

## 1. Столпы трасс

1. **Рельеф читается ногами и глазами.** Подъём — это настоящий склон в кадре (дорога уходит
   вверх, горизонт опускается), а SIM даёт его ногам (FRD-04). Профиль в HUD и в меню —
   тот же рельеф, что в 3D.
2. **Каждая трасса узнаётся по одному кадру без подписи** (D3D-08.8): плоский горизонт,
   волны холмов, высокие склоны, вода и мост.
3. **Час без скуки.** Каждые 1–3 минуты (0.6–1.5 км при 30 км/ч) на горизонте или у
   дороги появляется новый ориентир. Ориентиры перечислены по километрам в каждой трассе.
4. **Один мир — один набор.** Трасса = профиль + план-схема + свой `EnvironmentSet`
   (D3D-06). Игровой цикл не меняется.

## 2. Модель данных трассы (предложение для developer / technical-artist)

Один ресурс на трассу, например `src/scene3d/tracks/<id>.tres` (`TrackDef`):

| Поле | Смысл |
|---|---|
| `id` | `flat`, `hills`, `mountains`, `seaside` (D3D-08.1) |
| `name_key`, `kind_key` | ключи локализации названия и типа (п. 3) |
| `length_m` | длина круга |
| `profile_km_m` | опорные точки (s, км → h, м) из таблиц ниже; первая и последняя совпадают |
| интерполяция | **PCHIP, периодическая** (монотонная кубика Фрича–Карлсона, касательная на стыке — по соседям через стык). Без выбросов над опорными точками, гладкая, на экстремумах ровная. Выборка в массив высот с шагом 10 м при загрузке (D3D-08: точки не реже 10 м) |
| `bridges` | диапазоны s моста (приморье) |
| `water_level_m` | уровень воды (приморье) |
| `layout` | параметры план-схемы (п. 4 у каждой трассы) и `seed` |
| `environment_set` | путь к `EnvironmentSet` (`.tres`) |
| `mood_color` | цвет полосы настроения на карточке (`ui.md` п. 8.4) |
| `landmarks` | список (s, тип) — ориентиры из п. 4 |

Характеристики считаются по выборке ровно так, как в D3D-08: **набор** — сумма
положительных приращений за круг; **уклон** — Δh/Δs по окну 100 м; **макс. уклон** —
максимум за круг; **подъём** — участок с уклоном > 2 % длиной ≥ 300 м. Все числа в
таблицах ниже посчитаны так по опорным точкам (PCHIP, шаг 10 м, окно 100 м).

## 4. Трассы

### 4.1. `flat` — Пшеничные поля

**Профиль** (км → м): 0.0 → 40, 1.2 → 42, 2.4 → 47, 3.3 → 45, 4.5 → 38, 5.6 → 36,
6.6 → 41, 7.5 → 48, 8.4 → 46, 9.2 → 42, 10.0 → 40. Еле заметные увалы ±6 м: на этой
трассе крутят темп и интервалы, а не подъёмы.

**План-схема.** Неправильный четырёхугольник с длинными прямыми 1.2–2 км и широкими
дугами R 250–600 м. Прямых — около 50 % длины. Поворотов круче R 200 м нет. В генераторе
типа `LoopTrack`: 10–12 опорных точек, `waviness` 0.15, плюс участки прямых.

**Окружение (что меняется относительно мира «холмов»):**
- Рельеф горизонта низкий: `hills_height_m` 18 (вместо 120), `rolling_height_m` 2.
  Горизонт плоский и далёкий, это и есть узнаваемость кадра.
- Поля полосами-«лоскутами» вдоль дороги по маске: пшеница (0.86, 0.74, 0.40) / (0.78, 0.64, 0.32),
  пашня (0.52, 0.40, 0.30), зелёный клевер (0.42, 0.62, 0.28). Лоскуты — цвет вершин земли,
  без новой геометрии.
- Деревья не рощами, а лесополосами: ряды тополей-«свечей» (новая крона — вытянутый
  конус-эллипсоид) вдоль полей, 2–3 полосы в поле зрения; ели реже. Кусты у кювета.
- Отбойника почти нет (только у мостика через ручей на 7.5 км). Столбики — как сейчас.
- Свет: позднее утро, солнце ниже и теплее (1.0, 0.93, 0.80), энергия 0.85. Дымка у
  горизонта тёплая (0.85, 0.86, 0.82), туман 0.0005 — видно далеко.

**Ориентиры:** 0.8 км — водонапорная башня; 1.9 — ряд ветряков на горизонте слева
(медленно вращаются, 6–8 шт.); 3.0 — стога (группа 5 шт.); 4.2 — деревня из 6–8 домиков
с красными крышами справа; 5.4 — элеватор; 6.4 — подсолнуховое поле; 7.5 — мостик через
ручей, ивы; 8.6 — ветряки ближе, справа; 9.5 — ферма с силосной башней.

### 4.2. `hills` — Зелёные холмы

**Профиль:** 0.0 → 120, 0.6 → 122, 1.5 → 160, 2.1 → 158, 2.8 → 132, 3.6 → 128,
4.9 → 196, 5.4 → 200, 6.4 → 165, 7.2 → 158, 8.0 → 194, 8.5 → 191, 9.5 → 150,
10.2 → 146, 12.2 → 218, 12.7 → 214, 14.0 → 140, 15.0 → 120.

| Подъём | Начало | Длина | Набор | Средний уклон |
|---|---|---|---|---|
| 1 | 0.67 км | 0.75 км | +36 м | 4.8 % |
| 2 | 3.70 км | 1.17 км | +66 м | 5.7 % (макс. 7.5 %) |
| 3 | 7.27 км | 0.67 км | +35 м | 5.2 % |
| 4 | 10.41 км | 1.59 км | +68 м | 4.3 % |

Ритм — «пила»: подъём на 2–5 минут, спуск, ровный отрезок. Хорошо для интервалов по
ощущениям и для длинных Z2.

**План-схема.** Извилистая петля: повороты R 80–250 м, связки S-образных поворотов на
спусках, прямые не длиннее 600 м. 16–18 опорных точек, `waviness` 0.3. Дорога идёт по
склонам: на подъёме склон с одной стороны выше дороги, с другой открывается вид.

**Окружение — нынешний мир** (арт-библия) с поправками:
- `hills_height_m` 160, `rolling_height_m` 12 — волнистый горизонт, ряды холмов один за
  другим.
- Рощи на вершинах холмов, луга на склонах, у дороги одиночные дубы; каменные изгороди
  (низкая лента-стенка, цвет бордюра) вдоль полей на 30 % длины.
- Отбойник на внешней стороне поворотов на спуске.
- Свет и палитра — как сейчас.

**Ориентиры:** 0.5 — каменный мост через ручей; 1.5 — вершина 1, часовня; 2.6 —
пасущиеся овцы (группа белых «облачков»); 3.6 — хутор у подножия; 5.4 — вершина 2,
одинокое большое дерево и скамейка; 6.8 — ветряная мельница; 8.0 — вершина 3, вид на
озеро внизу; 9.8 — деревня; 12.2 — вершина 4, телевышка; 13.4 — виноградник рядами.

### 4.3. `mountains` — Перевал

**Профиль:** 0.0 → 300, 1.0 → 305, 2.0 → 302, 3.0 → 312, 4.0 → 360, 5.0 → 416,
6.0 → 476, 7.0 → 530, 7.6 → 560, 8.4 → 625, 9.2 → 672, 10.0 → 732, 10.6 → 738,
11.2 → 732, 12.5 → 652, 14.0 → 548, 15.5 → 452, 17.0 → 362, 18.2 → 318, 19.2 → 304,
20.0 → 300.

Один подъём на **6.98 км с набором +420 м, в среднем 6.0 %** (с 3.03 до 10.0 км). Крутая
часть 7.6–9.2 км доходит до 8–9.4 %. Затем седловина перевала 10.0–11.2, спуск 8.8 км в
среднем −5 %, долина 0–3 км для разминки и восстановления. Это «Альп-д’Юэз в миниатюре»:
главное событие трассы — 25–35 минут подъёма.

**План-схема.**
- Долина (0–3 км и 17–20 км): прямые вдоль реки, R ≥ 300 м.
- Подъём: «змейка» из 6–8 виражей R 40–60 м на крутой части, между ними траверсы
  300–600 м по склону. Склон с внутренней стороны поднимается над дорогой (скальная
  стенка), с внешней открывается долина с отбойником. Настоящие шпильки R 15–25 м —
  второй шаг, когда проверим наклон гонщика и камеру на таких радиусах.
- Спуск — по другому склону, повороты R 80–150 м (на скорости 50+ км/ч).
- Камера на подъёме не задирается: она держит горизонтальную дистанцию (D3D-07.5), а
  уклон виден по дороге и уходящему вниз склону.

**Окружение:**
- Горизонт высокий: дальние пики `hills_height_m` 650–900 м над долиной, на вершинах снег
  (0.95, 0.97, 1.0), тень снега (0.75, 0.82, 0.95). Снег — по высоте вершин рельефа в
  шейдере земли, без новых мешей.
- Ближние склоны: альпийский луг (0.45, 0.62, 0.30) ниже 600 м, выше — камень
  (0.55, 0.54, 0.56) / (0.42, 0.42, 0.46), осыпи, валуны (новый тип объекта — низкополигональный
  камень с контуром).
- Растительность: только ели (больше и темнее), лиственных нет; выше 650 м деревьев нет.
- Отбойник по внешней стороне на всём подъёме и спуске, каменные столбики-«зубья» вместо
  сигнальных на перевале.
- Табличка «км до вершины» каждый километр подъёма (белая с чёрными цифрами). Это
  ориентир в мире, и он рифмуется с подвалом HUD «до вершины 4.2 км».
- Свет: воздух прозрачнее, туман 0.00045, небо глубже — зенит (0.24, 0.48, 0.86),
  горизонт (0.70, 0.80, 0.92); окружающий свет холоднее (0.52, 0.60, 0.84). Дымка
  слоями в долине: облако ниже уровня перевала (плоские облака, уже есть в `sky.gdshader`,
  на высоте ~550 м).

**Ориентиры:** 0.5 — деревня в долине с колокольней; 2.0 — горная речка и каменный мост;
3.0 — подножие, табличка «Перевал 7 км»; 4.0…10.0 — таблички «6…1 км»; 5.2 — водопад
на склоне слева; 7.6 — начало змейки, вид на долину; 9.0 — облака под дорогой; 10.4 —
перевал: каменный знак, флажки, кафе-шале; 12.0 — горное озеро внизу справа; 14.5 —
тоннель-галерея (навес над дорогой 150 м); 16.5 — пастбище с коровами; 18.5 — снова
деревня.

### 4.4. `seaside` — Приморье

**Профиль:** 0.0 → 12, 1.0 → 14, 2.0 → 13, 3.0 → 16, 4.0 → 12, 4.8 → 8, 5.5 → 7,
5.70 → 12, 5.90 → 14, 6.25 → 14, 6.45 → 9, 7.0 → 8, 7.6 → 24, 8.2 → 48, 8.6 → 52,
9.1 → 46, 10.0 → 26, 11.0 → 14, 12.0 → 12.

- **Мост:** пролёт над рекой — **s = 5.82–6.33 км** (`bridges = [(5820, 6330)]`), полотно на
  14 м над водой (`water_level_m = 0`), ровное на 5.90–6.25 км. Подходы — насыпи 2–3 %
  (5.50–5.82 и 6.33–6.45).
- Один подъём на мыс с маяком: с 7.16 км, 1.02 км, +38 м, в среднем 3.7 % (макс. 4.9 %).
  Остальное — ровная набережная у самой воды.

**План-схема.** Петля в форме «D»: прямая сторона 0–4.8 км — береговая дорога вдоль моря
(море справа по ходу, то есть с внешней стороны петли), дуга — через мыс и сосновый лес
обратно. Река начинается из озера **внутри** петли и впадает в море, поэтому петля
пересекает её **один раз** — одним мостом. Повороты на набережной R 300–800 м, на мысу
R 60–120 м.

**Окружение — главное отличие трассы:**
- **Вода.** Одна большая плоскость моря до горизонта и полоса реки. Тун-вода в два тона:
  глубокая (0.10, 0.42, 0.62), мелкая (0.22, 0.68, 0.75) по глубине под водой; полоса пены
  у берега (0.95, 0.97, 0.98) — анимированные штрихи; блик солнца — тун-полоса, без
  отражений и SSR. Один материал, без прозрачности (дешёво на мобильных).
- **Пляж и дюны** между дорогой и водой: песок (0.90, 0.82, 0.62), дюнная трава
  (0.62, 0.66, 0.36), пляжные зонтики группами, лодки на берегу, буйки.
- **Мост:** балочный, 3 опоры, бетон (0.74, 0.74, 0.72), перила светлая сталь
  (0.78, 0.82, 0.86) вместо отбойника, фонари каждые 40 м. Под мостом вода реки, по
  берегам — камыши. Мост должен быть виден за 300–400 м до въезда (ориентир, D3D-08.8).
- **Растительность:** зонтичные сосны (новая крона: плоский «зонт» на тонком стволе,
  (0.30, 0.48, 0.25)), кипарисы у домиков; лиственных мало.
- Рельеф: `hills_height_m` 60 только со стороны суши (маска «суша/море»), со стороны моря
  рельефа нет — горизонт открыт.
- Свет: светлый, высокий ключ: зенит (0.30, 0.62, 0.92), горизонт (0.80, 0.90, 0.96),
  туман 0.0006 цвета (0.80, 0.88, 0.94), солнце (1.0, 0.95, 0.86), энергия 0.9.
  Тени остаются холодными (арт-библия).

**Ориентиры:** 0.6 — рыбацкий причал с лодками; 1.8 — пляж с зонтиками; 3.0 — белые
домики с синими ставнями; 4.2 — парусник на горизонте (медленно плывёт); 5.0 — устье
реки, камыши; 5.8–6.3 — мост; 7.0 — сосновый лес; 8.6 — маяк на мысу (белый с красными
полосами (0.80, 0.20, 0.18)), вид на море сверху; 9.8 — скалы и брызги у подножия мыса;
11.0 — набережная с фонарями.

## 5. Общие правила мира для длинных трасс (для technical-artist)

- **Высота дороги = профиль** (D3D-08.4). Рельеф у дороги следует за полотном: полоса
  травы и кювет — относительно высоты полотна, а не абсолютного нуля.
- **Склон вдоль подъёма.** На трассах с подъёмами ближний рельеф (до 60 м от дороги)
  наклонён поперёк дороги: с внутренней стороны поворота выше, с внешней ниже. Без этого
  подъём выглядит как «дорога на насыпи».
- **Плотность объектов — на километр, а не на трассу.** Сейчас 380 деревьев на 2.1 км
  (≈ 180/км). На 20 км это 3600 экземпляров. Нужно делить MultiMesh на куски по ~500 м с
  `visibility_range` (видно ±1.5 км вокруг гонщика) — тогда в кадре столько же, сколько
  сейчас (бюджет `docs/perf_budget.md`).
- **Сетка рельефа.** `TerrainField` строит одну сетку по габариту трассы (`MAX_CELLS` 150).
  На петле 20 км ячейка будет ~50 м, а горы и мыс потеряют форму. Нужна сетка-коридор
  вдоль трассы или куски сетки с LOD. Это главный технический риск D3D-08.
- **Ориентиры** — отдельные сцены или меши, по одному экземпляру. В кадре одновременно
  не больше 2–3, остальные отсечены по дистанции.
- **Новые типы объектов** (тополь, зонтичная сосна, кипарис, камень, домик, ветряк,
  маяк, мост, табличка) — низкополигональные, с контуром по правилам арт-библии, цвет
  вершин из палитры трассы. Источник каждого ассета — в `assets.md`. CC0 (Kenney,
  Quaternius) допустимы только после перекраски в тун-палитру и с контуром.

| Мост: бетон / перила | (0.74, 0.74, 0.72) / (0.78, 0.82, 0.86) |
| Крыши (деревни) | (0.78, 0.32, 0.24) |
| Маяк: полосы | (0.95, 0.95, 0.93) / (0.80, 0.20, 0.18) |

Правило арт-библии остаётся: насыщенность мира не выше средней, цвета зон HUD в мире не
используются. Красные крыши и маяк — мелкие и далёкие акценты, не крупнее 3 % кадра.

## 7. Превью трассы

Палитра уклона — общая с HUD (`hud.md` п. 11): < −2 % сланец, −2…2 % шалфей, 2…4 % песок,
4…7 % терракота, 7…10 % кирпич, ≥ 10 % вино. Уклон считается по окну 100 м, как в D3D-08.

### 7.1. Миниатюра на карточке (каталог, главный экран)

- Фон `inset`, радиус 12, поля 12. Сверху вниз лёгкий градиент `mood_color` с альфой
  0.10 → 0, чтобы четыре карточки различались цветом настроения.
- Ось X — круг целиком на всю ширину. Ось Y — **своя у карточки, размах
  max(перепад трассы, 150 м)**, низ — минимум трассы. Получаем: равнина — едва заметная
  волна (8 % высоты), приморье — 30 %, холмы — 65 %, горы — 100 %. Порядок «круче — выше»
  честный, и при этом каталог не выглядит пустым. Варианты и почему не они:
  - общая шкала 0–500 м для всех: честнее, но равнина и приморье становятся линией у
    дна, а карточки — пустыми (так было в первом макете);
  - своя шкала без минимума: равнина в ±6 м выглядит как горы, это обман.
- Заливка под профилем кусками по цвету уклона (кусок ≥ 2 lp), белый контур 1.5 lp с
  альфой 0.85. Подписей нет.
- Приморье: под диапазоном моста у нижнего края — полоса 4 lp цвета воды (0.30, 0.65, 0.95)
  и иконка `waves` 14 lp над ней. Горы: маленький треугольник-вершина 8 lp над максимумом.
- Под миниатюрой — ряд Stat: «20.0 км» круг, «441 м» набор, «9.4 %» макс. уклон.

### 7.2. Крупный профиль (деталь трассы, FRD-03)

- Высота ≈ 38 % панели детали, та же заливка и контур.
- Ось Y: размах max(перепад, 150 м). Слева две подписи: максимум и минимум высоты («738 м»,
  «300 м», Caption `tnum`) и тонкие линии сетки на этих высотах (`line`).
- Ось X: километры. Шаг — наименьший из 1, 2, 5, 10 км, при котором подписей ≤ 10 (как
  HUD-10.4). Подписи — Caption `tnum`.
- Подъёмы (уклон > 2 %, ≥ 300 м): над серединой каждого — подпись «подъём 7.0 км · 6.0 %»
  (12 / 650). Не больше трёх, самые длинные; у холмов — все четыре коротко: «1.2 км · 5.7 %».
- Линия старта и финиша — вертикаль пунктиром на 0 с флажком `flag` 14 lp. Мост —
  полоса воды, как в п. 7.1, и подпись «мост».
- Под профилем ряд Stat, затем слайдер крутизны SIM (`ui.md` п. 8.4).

### 7.3. В HUD и в истории

- HUD свободной езды — круг целиком и «впереди 2 км» (`hud.md` п. 8).
- Карточка заезда в истории (свободная езда) — профиль по проеханной дистанции: круги
  подряд, граница круга — пунктир. Если кругов больше 3 — шкала сжимается, подписи по км.

## 8. Предлагаемые критерии (для requirements, дополняют D3D-08 и FRD-03)

1. (D3D-08.1, .3) Профили трасс заданы опорными точками из п. 4 и интерполируются PCHIP
   (периодической) с выборкой 10 м; посчитанные характеристики равны таблице п. 3
   (длина ±0.1 км, набор ±5 м, макс. уклон ±0.3 %). `[авто]`
2. (D3D-08.3, приморье) Диапазон моста 5820–6330 м; на нём высота полотна над
   `water_level_m` ≥ 10 м; под мостом есть водная поверхность. `[авто]`
3. (D3D-08.6) У каждой трассы свой `EnvironmentSet`; параметры `hills_height_m`
   упорядочены: равнина < приморье < холмы < горы. `[авто]`
4. (D3D-08, столп 3) На каждой трассе ориентиры (`landmarks`) стоят не реже чем через
   1.5 км по s; по снимкам у трёх ориентиров на трассу ориентир виден в кадре. `[авто]` +
   `[визуальная проверка]`
5. (D3D-05, D3D-08.6) Число экземпляров MultiMesh, видимых с любой точки трассы (с учётом
   `visibility_range`), не больше бюджета `docs/perf_budget.md` на всех четырёх трассах. `[авто]`
6. (FRD-03, UIX-03) Миниатюра профиля использует размах Y = max(перепад, 150 м) и палитру
   уклона п. 7; на карточке — длина (1 знак), набор (целое, м), макс. уклон (1 знак, %). `[авто]`
7. (FRD-03) На крупном профиле подписаны подъёмы > 2 % и ≥ 300 м (не больше трёх),
   км-шкала по правилу п. 7.2, у приморья отмечен мост. `[авто]` + `[визуальная проверка]`
8. (D3D-08.8) Снимки каждой трассы на дистанциях: `flat` 0 / 1900 / 4200 / 7500 м;
   `hills` 0 / 4300 / 5400 / 6000 м; `mountains` 1000 / 6000 / 8600 / 10400 / 14500 м;
   `seaside` 1800 / 5600 / 6100 / 8600 м — чек-лист `ride-visual-review` ≥ 10/12, трассы
   различимы без подписи. `[визуальная проверка]`

## 9. Порядок работ

1. `TrackDef` и профиль: PCHIP, выборка 10 м, характеристики, тест чисел п. 3. Сначала
   на старом мире: дорога едет по профилю, рельеф подстраивается. Это даёт SIM и превью
   ещё до новых окружений. M.
2. Превью (миниатюра и деталь) и экран выбора трассы — сразу видно все четыре. S–M.
3. Длинные трассы в мире: коридорный рельеф, куски MultiMesh (п. 5). Без этого 15–20 км
   не уложатся в бюджет. L.
4. Окружения по наборам: холмы (почти готово) → равнина (поля-лоскуты, тополя, ветряки)
   → горы (камень, снег, змейка, таблички) → приморье (вода, пляж, мост). M каждое,
   приморье — L.
5. Ориентиры по спискам п. 4. M.
